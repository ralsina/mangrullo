Why Mangrullo?

Everything you need to keep your containers updated automatically

🔄

Automated Updates

Set it and forget it. Mangrullo monitors your containers and automatically updates them when new images are available. Choose from continuous polling or one-time checks.

🌐

Web Dashboard

Beautiful web interface to monitor all your containers, check for updates, and trigger updates with a single click. Sort, filter, and manage everything from your browser.

⚡

Real-Time Notifications

Watch update progress in real-time with Server-Sent Events. See exactly what's happening: pulling images, stopping containers, and recreating them live.

🐳

Multi-Architecture

Full support for AMD64 and ARM64 architectures. Run Mangrullo anywhere Docker runs, from your home server to cloud infrastructure.

🔒

Configuration Preservation

Update without worry. Mangrullo preserves all container configurations, volumes, environment variables, and settings when recreating containers.

🛡️

Smart Version Control

Control major version updates with precision. Use dry-run mode to preview changes, and decide which containers should update and when.

📊

Multi-Registry Support

Works seamlessly with Docker Hub, GitHub Container Registry (ghcr.io), and other registries. Automatic detection and authentication handling.

🚀

Zero Downtime

Containers are gracefully stopped, removed, and recreated with the new image. Your services stay available with minimal interruption.

🔔

Self-Update Protection

Mangrullo won't accidentally update itself through the web UI. Get helpful manual update instructions instead of unexpected service interruptions.

Quick Start

Get up and running in seconds with Docker

Docker Run (CLI Mode)

docker run -d \
  --name mangrullo \
  -v /var/run/docker.sock:/var/run/docker.sock \
  ghcr.io/ralsina/mangrullo:latest

Docker Run (Web Mode)

docker run -d \
  --name mangrullo-web \
  -p 3000:3000 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  ghcr.io/ralsina/mangrullo:latest web

Docker Compose

services:
  mangrullo-web:
    image: ghcr.io/ralsina/mangrullo:latest
    ports:
      - "3000:3000"
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
    command: web

Check for Updates

# One-time check
docker run --rm \
  -v /var/run/docker.sock:/var/run/docker.sock \
  ghcr.io/ralsina/mangrullo:latest --once
